# 结构体基础知识
结构是一种集合
数组是一种类型相同的集合
==结构是一些值的集合，这些值被称为成员变量。结构每个成员可以是不同类型变量==

---
# 结构体声明
```c
struct tag{
	member-list;
}variable-list//可有可无;
```
eg.
```c
struct Peo{
	char name[20];
	char tele[12];
	char sex[5];//一个汉字两个字符
	int high;
}p1,p2;//用struct Peo结构类型创建的两个变量，此处为全局变量

struct St{
	struct Peo p;
	int num;
	float f;
};

void print2(struct Peo* sp){
	printf("%s %s %s %d\n",sp->name, sp->tele, sp->sex, sp->high);
}

void

int main(){
	struct Peo p1 = {“张三”,“13915245618”,“男”,“181”};//结构体变量声明，此处为局部变量
	struct St s = {{"lisi", "13915425618", "女","168"}, 100, 3.14f//浮点数不能精确保存};
	
	printf("%s %s %s %d\n", p1.name, p1.tele, p1.sex, p1.high);
	printf("%s %s %s %d %d %f\n",s.p.name, s.p.tele ,s.p.sex, s.p.high, s.num, s.f);
}
```

| 变量   | p1是结构体变量 |
| ---- | -------- |
| 图纸   | 🏠       |
| 不占内存 | 占内存      |
