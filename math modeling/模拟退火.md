## 模拟退火流程

**核心思想**：模仿金属退火——高温时原子能自由乱跑，慢慢降温后才稳定到能量最低的状态。算法上对应：高温时敢接受坏解（逃出局部最优），低温时只接受好解（精细收敛）。

------

**流程步骤**

1. **初始化**
   - 随机生成初始解 x
   - 设定初始温度 T₀（要够高）、降温率 α（一般 0.9~0.99）、终止条件
2. **产生新解**
   - 在当前解 x 附近随机扰动，得到 x_new = x + dx
3. **计算代价差**
   - Δ = f(x_new) − f(x)
4. **Metropolis 准则判断是否接受**
   - 若 Δ < 0（新解更好）→ **直接接受**，x ← x_new
   - 若 Δ ≥ 0（新解更差）→ **以概率 exp(−Δ/T) 接受**
     - 具体做法：抽 r ~ U(0,1)，若 r < exp(−Δ/T) 则接受，否则保持原解
5. **降温**
   - T ← α · T
6. **判断终止**
   - 达到最大迭代次数、温度低于阈值，或解长时间不更新 → 输出当前最优解
   - 否则回到第 2 步

------

**关键直觉**

- **温度 T 控制"冒险程度"**：T 大时 exp(−Δ/T) 接近 1，几乎什么坏解都接受；T 小时接近 0，只接受好解
- **降温要慢**：降太快等于直接贪心，停在局部最优；降太慢浪费时间
- **接受坏解是特性不是 bug**：这正是 SA 区别于普通爬山法、能逃出局部最优的关键

------

**伪代码**

```
初始化 x, T = T₀
while 未终止:
    x_new = x + 随机扰动
    Δ = f(x_new) - f(x)
    if Δ < 0:
        x = x_new
    elif rand() < exp(-Δ/T):
        x = x_new
    T = α * T
return x
```

整个算法的灵魂就一句话：**好解必收，坏解看运气，运气随温度递减**。
