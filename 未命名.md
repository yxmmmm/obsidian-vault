**English:**
If you move from one programming language to another that carries out similar tasks but with different syntax - say, from JS to TS, or C++ to Java, or Rust to Go once you've learned the first set of concepts, you'll know a lot of the concepts needed to prompt an LLM to code in the second language. ### 段落四：选自《计算机代码究竟是语言还是数学？》

**English:**
The study, carried out by a team from MIT and Tufts University, had two dozen participants read code, English, and logic puzzles while in an fMRI machine. By seeing which parts of the brain lit up while doing these tasks, the researchers could determine how our brains process coding languages. If the areas of the brain associated with language processing were to light up, then we treat code like we treat languages.  The same would go for the math parts. The control tasks, reading either a real sentence or a nonsense one and memorizing the location of colored squares, demonstrated the baseline activation levels for these systems in each subject. 

**中文翻译:**
这项由麻省理工学院和塔夫茨大学团队开展的研究，让二十多名参与者在功能磁共振成像（fMRI）机器中阅读代码、英语和逻辑谜题。通过观察在执行这些任务时大脑的哪些部分会亮起，研究人员就可以确定我们的大脑是如何处理编程语言的。如果与语言处理相关的大脑区域亮起，那就说明我们像对待语言一样对待代码。数学部分也是如此。对照任务，如阅读一个真实的句子或一个无意义的句子，以及记住彩色方块的位置，展示了每个受试者大脑中这些系统的基线激活水平。

### 段落五：选自《计算机代码究竟是语言还是数学？》

**English:**
When the subjects were in the machine, they were asked to work through the code and predict the output. The brain scans showed only limited responses in the brain's language processing centers, but a considerable amount in the multiple demand (MD) system, which often handles math, logic, and executive tasks. While this may sound like a win for the "coding is math" argument, it isn't quite the slam dunk you might think it is. This system handles most of our "difficult" thinking and is useful for many things. Logic and math typically cause the left half of it to fire up while the right half handles abstract thinking. 

**中文翻译:**
当受试者在机器中时，他们被要求通读代码并预测输出结果。脑部扫描显示，大脑的语言处理中心的反应非常有限，但在多重需求（MD）系统中有相当大的反应，该系统通常处理数学、逻辑和执行任务。虽然这听起来像是“编码就是数学”这一论点的胜利，但这并不像你想象的那么确凿。这个系统处理了我们大部分的“困难”思考，并在很多方面都很有用。逻辑和数学通常会激活它的左半球，而右半球则处理抽象思维。
