## 面向对象和面向过程
面向过程是执行者思维，解决简单问题
面向对象是设计者思维，解决复杂问题

### 类
根据类的定义来造出对象
类：我们叫做class   对象：我们叫做object，instance（实例）

#### 属性和方法
我们通过类定义数据类型的属性和方法
属性是类的静态数据，方法是类的动态行为

定义类的语法格式：
```
class 类名：
	类名
```

1.类名必须符合“标识符”的规则；一般规定首字母必须大斜，多个单词用“驼峰规则”
2.类体中我们可以定义属性和方法
3.属性用来描述数据，方法（即函数）用来描述这些数据相关的操作 

【操作】一个典型的类的定义
```
class Student:  
  
    def __init__(self,name,score):  
        self.name = name  
        self.score = score   
    def say_score(self):  
        print("{0}的分数是{1}".format(self.name,self.score))  #如果前面没有定义self就无法调用前面属性的数据，因为这是在局部函数中
  
s1 = Student("张三",80)  
print(s1.name,s1.score)  
s1.say_score()  
s2 = Student("李四",90)  
print(s2.name,s2.score)
```
pass为空语句，表示什么都不做，只是作为一个占位符存在
当你暂时不知道往方法或者类中加什么时，可以先用pass占位，后期补上

__init__()   的要点

2.第一个参数固定，必须是：self
3.构造函数通常用来初始化实例对象的实例属性
```

	self.name = name #实例属性
	self.score = score 
```

4.通过“类名（参数列表）”来调用构造函数，调用后将创建好的对象返回给相应的变量
s 1= Student（“张三”，80）

7, 如果我们不定义`__init__`方法，系统会提供一个默认的`__init__`方法。如果我们定义了带的`__init__`方法，系统不创建默认的`__init__`方法

#### 类方法
类方法是从属于“类对象”的方法
类方法通过装饰器@classmethod来定义
格式：
```
@classmethod
def 类方法名（cls [,形参列表]）
	方法体
```

1、@classmethod 必须位于昂发上面一行
2、第一个cls必须有，cls指的就是“类对象”本身
3、调用类方法格式：类名.类方法名（参数列表）
4、==类方法中访问实例属性和实例方法会导致错误==
5、子类继承父类方法时，传入cls是子类对象，而非父类对象

【操作】类方法使用测试
```
class Student:  
    company = "SXT"  
  
    @classmethod  
    def printCompany(cls):  
        print(cls.company)  
  
Student.printCompany()
```

#####  静态方法
Python中允许定义与“类对象”无关的方法，称为“静态方法”。

“静态方法”和在模块中定义普通函数没有区别，只不过“静态方法”放到了“类的名字空间里面”，需要通过“类调用”。

静态方法通过装饰器@staticmethod来定义，格式如下：
```
@staticmethod
def 静态方法名（[形式列表]）：
	方法体
```

1. `@staticmethod`必须位于方法上面一行
2. 调用静态方法格式：`类名.静态方法名(参数列表)`
3. 静态方法中访问实例属性和实例方法会导致错误

【操作】静态方法使用测试
```
class Student:  
    company = "SXT"  
  
    @classmethod  
    def printCompany(cls):  
        print(cls.company)  
  
    @staticmethod  
    def add(a,b):  
        print("{0} + {1} = {2}".format(a,b,a+b))  
        return a+b  
  
Student.printCompany()  
Student.add(1,2)
```
静态方法与类没有关系，但是使用时按照类来使用

## del析构方法和垃圾回收机制
`__del__()`称为“析构方法”，用于实现对象被销毁时所需的操作。比如：释放对象占用的资源，例如：打开的文件资源、网络连接等。

Python实现自动的垃圾回收，当对象没有被引用时（引用计数为0），由垃圾回收器调用`__del__()`。

我们也可以通过`del语句`删除对象，从而保证调用`__del__()`。

系统会自动提供`__del__方法`，一般不需要自定义析构方法。
```
class Person:  
  
    def __del__(self):  
        print("销毁对象：{0}".format(self))  
  
p1=Person()  
p2=Person()  
del p1  
print("程序结束")
```
输出结果
```
销毁对象：<__main__.Person object at 0x00000237FE86CEC0>
程序结束
销毁对象：<__main__.Person object at 0x00000237FEBD8F50>
```

## 私有属性、私有方法
Python对于类的成员没有严格的访问控制限制，这与其他面向对象语言有区别。关于私有属性和私有方法，有如下要点：

1. 通常我们约定，两个下划线开头的属性是私有的(private)。其他为公共的(public)。
2. 类内部可以访问私有属性(方法)
3. 类外部不能直接访问私有属性(方法)
4. 类外部可以通过`_类名__私有属性(方法)名`”访问私有属性(方法)

```
class Employee:  
    __company = "baizhan"  
  
    def __init__(self,name,age):  
        self.name = name  
        self.age = age  
  
    def say_company(self):  
        print("我的公司是：",Employee.__company)  
        print("我的年龄是：",self.age)  
  
    def __work(self):  
        print("努力工作，好好赚钱")  
  
  
print(dir(Employee))  
print(Employee._Employee__company)  
a = Employee("ql",18)  
print(a.name)  
print(a.age)  
  
a.say_company()  
a._Employee__work()
```

## 继承详解
子类扩展父类，代码的复用

语法：
Python支持多重继承，一个子类可以继承多个父类

```
class 子类类名[父类1[父类2，  ....]]
	类体
```

如果在类定义指令没有指定父类，就默认父类是object类。 也就是说，object是所有类的父类，里面定义了所有类的类    

```
class Person:  
    def __init__(self, name, age):  
        print("创建Person")  
        self.name = name  
        self.age = age  
  
    def say_age(self):  
        print("{0}的年龄{1}".format(self.name,self.age))  
  
class Student(Person):  
    def __init__(self, name, age, score):  
        #调用父类方法和属性可以使用如下两种方法  
        #Person.__init__(self, name, age)  
        super(Student,self).__init__(name, age)  
        print("创建Student")  
        self.score = score  
  
  
s1 = Student("ql",18,90)  
s1.say_age()  
print(dir(s1))
```

关于构造函数 
子类不重写__init__,会自动分调用父类定义的__init__
子类如果重写了__init__,就不会调用父类已经定义的__init__
如果重写了__init__，要继承父类，可以使用super关键字

也可使用如下：
```
父类名.__init__(self,参数列表)
```

### 成员继承
子类继承了父类除构造方法之外的所有成员
（私有属性和私有方法也被继承）

方法重写:子类可以重新定义父类中的方法，这样就会覆盖父类的方法，也称为”重写“

```
class Person:  
    def __init__(self, name, age,score):  
        print("创建Person")  
        self.name = name  
        self.__age = age  
        self.score = score  
  
    def say_age(self):  
        print("{0}的年龄{1}".format(self.name,self.__age))  
  
    def say_score(self):  
        print(self.name, "的分数是：", self.score)  
  
    def say_name(self):  
        print("我是", self.name)  
  
class Student(Person):  
    def __init__(self, name, age, score):  
        # 关键步骤：调用父类的初始化方法  
        # 这行代码会执行 Person.__init__(self, name, age, score)        # 从而设置好 self.name, self.__age, 和 self.score        super().__init__(name, age, score)  
  
        # 如果子类有自己特有的属性需要初始化，可以写在这里  
        # 例如：  
        # self.student_id = student_id  
        self.score = score  
        self.age = age  
        self.name = name  
  
    def say_score(self):  
        print(self.name,"的分数是：",self.score)  
  
    def say_name(self):  
        print("报告老师，我是",self.name)    #重写  
s1 = Student("ql",18,90)  
s1.say_age()  
s1.say_score()  
s1.say_name()  
print(dir(s1))
```

## 重写`__str__()`方法
1. `object`有一个`__str__()`方法，用于返回一个对于“对象的描述”。内置函数`str(对象)`,调用的就是`__str__()`
2. `__str__()`经常用于`print()`方法，帮助我们查看对象的信息。`__str__()`可以重写

```
class Person:  
    def __init__(self,name,age):  
        self.name = name  
        self._age = age  
  
    def __str__(self):  
        "讲对象转化成一个字符串，一般用于print方法"  
        print("重写__str__方法")  
        return "名字是：{0},年龄是{1}".format(self.name,self._age )  
  
p = Person("ql",18)  
print(p)  
s = str(p)
```

运行结果：

```

名字是：ql,年龄是18
重写__str__方法
```

## 多重继承
Python支持多重继承，一个子类可以有多个“直接父类”。这样，就具备了“多个父类”的特点。但是由于，这样会被“类的整体层次”搞的异常复杂，尽量避免使用。
