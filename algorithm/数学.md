#### 欧拉筛

n只会被最小质因子筛掉

```cpp
bool st[N];
vector<int>primes;
void getprime(int n)
{
    for(int i=2;i<=n;i++)
    {
        if(!st[i])primes.push_back(i);
        for(int j=0;primes[j]<=n/i;j++)
        {
            st[primes[j]*i]=true;
            if(i%primes[j]==0)break;//保证是被最小质因子筛去防止重复筛出导致时间复杂度趋近埃势筛
        }
    }
}
```

最快的一集

$o(n)$

## 约数

### 试除法

#### 求约数

```cpp
vector<int> get_divisors(int x)
{
    vector<int> res;
    for (int i = 1; i <= x / i; i ++ )
        if (x % i == 0)
        {
            res.push_back(i);
            if (i != x / i) res.push_back(x / i);
        }
    sort(res.begin(), res.end());
    return res
}
```

依旧严格$o(\sqrt{n})$

## 快速幂

速求$a^kmod p$

$o(logn)$

![70af1e310392b6055880f24fd522d3ad](https://tuchuang-1387570672.cos.ap-nanjing.myqcloud.com/obsidianvault70af1e310392b6055880f24fd522d3ad.jpg)

```cpp
int qmi(int a, int k, int p)
{
    int res = 1;
    while (k)
    {
        if (k & 1)// 如果当前二进制位为 1，累乘到结果中
            res = res * a % p;
        k >>= 1;// 指数右移一位，处理下一个二进制位
        a = a * a % p;// 底数倍增：a 变成 a^2
    }
    return res;
}
```
