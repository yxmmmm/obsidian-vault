## 质数

### 试除法



判断指标 $i*i>=n$ 会导致溢出

换成$i>=n/i$

时间复杂度 $o(\sqrt{n})$

1-n中有$n/ln(n)$ 个质数

大约$o(nloglogn)$奇快无比



#### 欧拉筛

n只会被最小质因子筛掉

```cpp
bool st[N];
vector<int>primes;
void getprime(int n)
{
    for(int i=2;i<=n;i++)
    {
        if(!st[i])primes.push_back(i);
        for(int j=0;primes[j]<=n/i;j++)
        {
            st[primes[j]*i]=true;
            if(i%primes[j]==0)break;//保证是被最小质因子筛去防止重复筛出导致时间复杂度趋近埃势筛
        }
    }
}
```

最快的一集

$o(n)$
