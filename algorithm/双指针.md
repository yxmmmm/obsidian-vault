##  为什么是 $O(n)$ 而不是 $O(n^2)$？

判断复杂度最简单的方法是看**每个元素被操作了几次**。

- **在暴力循环中**：元素 $j$ 会被访问 $n$ 次。
- **在双指针中**：虽然有嵌套结构，但左指针 $i$ 最多移动 $n$ 次，右指针 $j$ 也最多移动 $n$ 次。
- **总计**：$n + n = 2n$ 次操作。根据大 O 表示法，这依然是 **$O(n)$**。

# 示例

https://www.acwing.com/problem/content/801/

最长不重复子序列

⚠️i往后移动时j只会往后移，j是单调的

```cpp
#include <iostream>

using namespace std;

const int N = 100010;

int n;
int q[N], s[N];

int main()
{
    scanf("%d", &n);
    for (int i = 0; i < n; i ++ ) scanf("%d", &q[i]);

    int res = 0;
    for (int i = 0, j = 0; i < n; i ++ )
    {
        s[q[i]] ++ ;
        while (j < i && s[q[i]] > 1) s[q[j ++ ]] -- ;//缩减到符合条件的最大区间
        res = max(res, i - j + 1);
    }

    cout << res << endl;

    return 0;
}
```
