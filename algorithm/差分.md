# 一维差分

## 思路及方法



![IMG_E644B29BAACB-1](https://tuchuang-1387570672.cos.ap-nanjing.myqcloud.com/obsidianvaultIMG_E644B29BAACB-1.jpeg)

避免构造b数组，通过**空降法**统一

### 1. 假设：万物始于 0

想象你面前有两排空白的格子（数组 $a$ 和数组 $b$），初始状态里面全是 **0**。

此时，差分关系是成立的：因为 $a$ 全是 0，其差分数组 $b$ 显然也全是 0。

### 2. 任务：把 0 变成题目给你的原数组 $a$

现在题目给了你一个初始数组，比如 $a = [1, 2, 3]$。

你可以把这个过程看作是 **3 次独立的“区间修改”操作**：

- **第 1 次**：在区间 $[1, 1]$ 加上 $a[1]$（即加上 1）。
- **第 2 次**：在区间 $[2, 2]$ 加上 $a[2]$（即加上 2）。
- **第 3 次**：在区间 $[3, 3]$ 加上 $a[3]$（即加上 3）。

### 3. 执行：调用同一个 `insert` 函数

在代码实现上，你只需要写好那个核心函数：

C++

```
void insert(int l, int r, int c) {
    b[l] += c;
    b[r + 1] -= c;
}
```

然后，构造初始差分数组的代码就变成了：

C++

```
for (int i = 1; i <= n; i++) {
    insert(i, i, a[i]); // 在 [i, i] 这个长度为 1 的区间上加 a[i]
}
```

------

### 为什么要这么做？（y 总的深意）

如果你不用“空降法”，你需要背两套公式：

1. **构造公式**：$b[i] = a[i] - a[i-1]$
2. **修改公式**：$b[l] += c, b[r+1] -= c$

但如果你用了“空降法”：

- **你只需要背一套 `insert` 逻辑。**
- 无论是在初始化数组，还是在后续处理题目给出的 $m$ 次区间修改时，你调用的都是同一个 `insert` 函数。

## 代码实现

https://www.acwing.com/problem/content/799/

```cpp
#include <iostream>

using namespace std;

const int N = 100010;

int n, m;
int a[N], b[N];

void insert(int l, int r, int c)
{
    b[l] += c;
    b[r + 1] -= c;
}

int main()
{
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i ++ ) scanf("%d", &a[i]);

    for (int i = 1; i <= n; i ++ ) insert(i, i, a[i]);

    while (m -- )
    {
        int l, r, c;
        scanf("%d%d%d", &l, &r, &c);
        insert(l, r, c);
    }

    for (int i = 1; i <= n; i ++ ) b[i] += b[i - 1];

    for (int i = 1; i <= n; i ++ ) printf("%d ", b[i]);

    return 0;
```

拉链法

```cpp
#include <iostream>

using namespace std;

const int N = 1010;

int n, m, q;
int a[N][N], b[N][N];

void insert(int x1, int y1, int x2, int y2, int c)
{
    b[x1][y1] += c;
    b[x2 + 1][y1] -= c;
    b[x1][y2 + 1] -= c;
    b[x2 + 1][y2 + 1] += c;
}

int main()
{
    scanf("%d%d%d", &n, &m, &q);

    for (int i = 1; i <= n; i ++ )
        for (int j = 1; j <= m; j ++ )
            scanf("%d", &a[i][j]);

    for (int i = 1; i <= n; i ++ )
        for (int j = 1; j <= m; j ++ )
            insert(i, j, i, j, a[i][j]);

    while (q -- )
    {
        int x1, y1, x2, y2, c;
        cin >> x1 >> y1 >> x2 >> y2 >> c;
        insert(x1, y1, x2, y2, c);
    }

    for (int i = 1; i <= n; i ++ )
        for (int j = 1; j <= m; j ++ )
            b[i][j] += b[i - 1][j] + b[i][j - 1] - b[i - 1][j - 1];

    for (int i = 1; i <= n; i ++ )
    {
        for (int j = 1; j <= m; j ++ ) printf("%d ", b[i][j]);
        puts("");
    }

    return 0;
}
```

开放寻址法

```cpp
#include <cstring>
#include <iostream>

using namespace std;

const int N = 200003, null = 0x3f3f3f3f;//N设成两倍大小，null设成极大值

int h[N];

int find(int x)
{
    int t = (x % N + N) % N;
    while (h[t] != null && h[t] != x)
    {
        t ++ ;
        if (t == N) t = 0;
    }//到结尾后从头扫描
    return t;
}

int main()
{
    memset(h, 0x3f, sizeof h);//初始化

    int n;
    scanf("%d", &n);

    while (n -- )
    {
        char op[2];
        int x;
        scanf("%s%d", op, &x);
        if (*op == 'I') h[find(x)] = x;//找到空坑并插入
        else
        {
            if (h[find(x)] == null) puts("No");//查看应该放置的下标有没有数
            else puts("Yes");
        }
    }

    return 0;
}
```
